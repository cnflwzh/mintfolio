# 静态博客基础能力

目标：Core 负责内容、路由和公开数据契约，主题负责呈现。产物仍为可部署到任意静态托管的 HTML/CSS/JS，不要求服务端账户、数据库或常驻进程。

本轮包含：公开内容发布策略（草稿、未来时间、本地预览）、文章固定链接与旧地址跳转、分页及独立分类/标签/系列页面、Markdown 独立页面和导航配置、作者与阅读统计、全文搜索、SEO/订阅、安全的内容检查。完成基础集成后新增三套明显不同的主题，并验证实际构建及浏览器表现。

兼容要求：已有文章和主题配置继续可用；公开 DTO 不包含密码和受保护正文；生产构建不包含本地预览内容；订阅与搜索使用相同公开规则。定时文章需要在发布时间之后重新构建。

本轮只在本地实现和验证，不自动部署用户站点。发布 npm/GitHub 前使用实际打包安装验证结果。
